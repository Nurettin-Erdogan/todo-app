# 60 saniyelik demo

1. [Canlı demoyu aç](https://gorev-listesi-pwa.vercel.app/).
2. Boş planda **Örnek planı yükle** ile üç görev ekle.
3. Bir görevi tamamla, birini sil, çıkan **Geri Al** ile geri getir.
4. Filtreleri (Aktif / Tamamlanan) ve aramayı dene.
5. Tarayıcıdan PWA olarak kur; ardından ağ olmadan da açıldığını göster.

Veriler sunucuya gitmez; yalnızca tarayıcı `localStorage` alanında kalır.
